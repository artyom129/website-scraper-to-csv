Project title:
Website Scraper to CSV

Short description:
I built a Python web scraper that extracts structured data from multiple website pages, handles pagination, removes duplicate records, and exports the results to a clean CSV file.

What it solves:
Businesses often need to collect product, lead, directory, or listing data from websites. This scraper automates the data collection process and saves time on manual copy-paste work.

Tech stack:
Python, requests, BeautifulSoup, CSV, web scraping, data extraction.

Client value:
This automation helps businesses collect structured website data faster, prepare clean CSV files, and use the data for reports, CRMs, research, or internal workflows.
