# Upwork Portfolio Entry

## Title

Multi-Page Website Scraper with CSV Export

## Description

Built a Python web scraper that collects structured product data across multiple pages, follows pagination links, removes duplicate records, and exports a clean CSV dataset.

The project separates page requests, HTML parsing, pagination, duplicate handling, and export logic so the workflow can be adapted to directories, listings, product catalogs, and permitted lead-generation sources.

## Technologies

Python, Requests, BeautifulSoup, CSV, HTML parsing, web scraping.

## Client value

The automation replaces repetitive manual data collection and produces structured records ready for spreadsheets, research, reporting, or CRM import.
